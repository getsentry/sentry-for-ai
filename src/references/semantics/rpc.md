# Rpc attributes

Generic RPC system attributes outside gRPC-specific keys.

| Key | Type | Brief |
| --- | --- | --- |
| `rpc.method` | `string` | The fully-qualified logical name of the method from the RPC interface perspective. |
| `rpc.response.status_code` | `string` | Status code of the RPC returned by the RPC server or generated by the client. |
| `rpc.service` | `string` | The full (logical) name of the service being called, including its package name, if applicable. |
| `rpc.system.name` | `string` | A string identifying the remoting system. |
